# 🛍️ Vrinda Store Sales Analysis — Excel Dashboard

## 📌 Project Overview

This project is an interactive **Excel Sales Analysis Dashboard** created using Vrinda Store sales data.

The dashboard analyzes sales and order performance across different months, customer demographics, states, sales channels, and order statuses.

The objective is to transform raw sales data into an interactive dashboard that provides clear business insights.

---

## 🎯 Business Objectives

The dashboard was created to analyze:

- Monthly sales and order trends
- Order performance
- Customer demographics
- State-wise sales performance
- Sales channel performance
- Order status distribution

---

## 📊 Analysis Performed

### 📈 Monthly Sales Analysis

- Analyzed monthly sales performance
- Compared monthly order volume
- Identified changes in sales throughout the year

### 📦 Order Analysis

- Analyzed overall order performance
- Examined order status distribution
- Compared delivered, cancelled, returned, and refunded orders

### 👥 Customer Demographics

- Gender-wise sales analysis
- Age-group analysis
- Customer order distribution

### 📍 State-wise Sales

- Compared sales across different states
- Identified top-performing states
- Analyzed geographic sales distribution

### 🛒 Sales Channel Analysis

Compared sales performance across different channels, including:

- Amazon
- Flipkart
- Myntra
- Meesho
- Nalli
- Ajio
- Other channels

### 🔄 Order Status Analysis

Analyzed different order statuses, including:

- Delivered
- Cancelled
- Returned
- Refunded
